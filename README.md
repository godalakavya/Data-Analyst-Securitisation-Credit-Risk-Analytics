## Business Context

Loan securitisation involves pooling financial assets such as auto loans
and analyzing their performance, credit quality, delinquency behavior,
losses, recoveries, and portfolio risk.

Financial institutions require effective data analytics to monitor loan
portfolios, identify delinquency patterns, evaluate credit risk, and
understand portfolio performance over time.

This project focuses on analyzing loan securitisation data and transforming
complex financial datasets into meaningful **credit risk insights, KPIs,
and interactive Power BI dashboards**.

------------------------------------------------------------------------

## Objective

The objective of this project is to develop a comprehensive **Loan
Securitisation & Credit Risk Analytics Solution** that:

-   Analyzes overall loan portfolio performance
-   Monitors loan balances and portfolio exposure
-   Evaluates delinquency and DPD patterns
-   Classifies loans using SMA risk categories
-   Analyzes defaults, recoveries, and losses
-   Evaluates vintage performance
-   Tracks portfolio-level risk indicators
-   Analyzes monthly loss and collection performance
-   Calculates important financial KPIs
-   Provides interactive dashboards for portfolio monitoring
-   Supports data-driven financial risk analysis

------------------------------------------------------------------------

## Problem Statement

-   Large loan portfolios require continuous monitoring and analysis.
-   Manual analysis of loan-level data can be time-consuming.
-   Delinquency and DPD patterns need to be monitored to identify
    potential credit risk.
-   Default and loss trends require detailed analysis.
-   Portfolio performance varies across different vintages.
-   Recoveries and collections need to be evaluated against losses.
-   Financial KPIs must be presented in a clear and interactive format.
-   A centralized dashboard is required for effective portfolio and
    risk monitoring.

## Data Analysis & Workflow

-   Collected and prepared loan securitisation datasets.
-   Performed data cleaning and validation using Python and Excel.
-   Processed loan portfolio and DPD snapshot data.
-   Performed **ETL and data transformation** for analytical reporting.

    trends and risk patterns.
-   Analyzed DPD buckets and delinquency behavior.
-   Evaluated SMA classifications and consecutive delinquency periods.

-   Analyzed monthly collection and loss performance.
-   Created calculated KPIs and measures using **Power BI and DAX**.
-   Developed interactive dashboards for executive and risk monitoring.
